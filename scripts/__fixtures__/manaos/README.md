# Fixtures de Manaos

Fragmentos reales de fuentes públicas, recuperados el 13/11/2026, para probar `scripts/datasets-manaos.mjs` sin red.

- `inep.csv`: 8 filas de `microdados_ed_basica_2024.csv` (INEP, Censo Escolar 2024), columnas reducidas, latin-1.
- `cnefe.csv`: 6 filas del CNEFE 2022 (IBGE), espécie 4, columnas reducidas, latin-1.
- `osm.json`: elementos `amenity=school` de OpenStreetMap (ODbL) devueltos por Overpass, UTF-8.
